# MVP: список завдань

Консольний застосунок Java демонструє патерн Model–View–Presenter на прикладі списку завдань.

## Ролі

- **Model** (`TaskModel`, `Task`) зберігає завдання та виконує операції над ними.
- **View** (`TaskView`, `ConsoleTaskView`) відповідає за консольне введення й виведення та передає дії Presenter.
- **Presenter** (`TaskPresenter`) обробляє дії користувача, працює з Model і оновлює View.
- `Main` створює компоненти та зв'язує View з Presenter.

Model не залежить від View, а Presenter працює з інтерфейсом `TaskView`, тому реалізацію інтерфейсу можна замінити, не змінюючи логіку Model.

## Запуск

Потрібен JDK. Із каталогу `PZ-MVP` виконайте:

```text
javac -d out src/*.java
java -cp out Main
```

## Команди

- `list` — показати завдання;
- `add <назва>` — додати завдання;
- `done <id>` — позначити завдання виконаним;
- `delete <id>` — видалити завдання;
- `help` — показати довідку;
- `exit` — завершити роботу.
